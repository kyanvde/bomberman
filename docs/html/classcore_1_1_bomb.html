core::Bomb Class Referencefinal

The Bomb class represents a bomb entity in the game world. It inherits from EntityModel and provides specific behavior for bomb entities: a countdown fuse, a blast radius, and collision rules that let anyone standing on its tile the moment it's placed walk off freely, after which it blocks them (including its own owner) like anyone else. Detailed Description

The Bomb class represents a bomb entity in the game world. It inherits from EntityModel and provides specific behavior for bomb entities: a countdown fuse, a blast radius, and collision rules that let anyone standing on its tile the moment it's placed walk off freely, after which it blocks them (including its own owner) like anyone else.
