An implementation observes the World read-only and returns a Decision; it never mutates the World directly – Character::onTick applies the decision through the same World::moveCharacter and World::placeBomb methods the human player's input uses, so there is no duplicated movement/bombing logic between player and bots

 CBasicAIControllerA baseline AIController satisfying the assignment's minimum bot behaviors, in priority order: flee imminent bomb danger, attack a nearby enemy (or any enemy once no destructible walls remain), bomb an adjacent destructible wall and retreat from it, seek a nearby power-up, and otherwise work toward the nearest destructible wall. Constructor parameters let different bot instances behave slightly differently without duplicating this decision logic
