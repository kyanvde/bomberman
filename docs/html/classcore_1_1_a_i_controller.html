Detailed Description

The AIController class is the strategy interface for computer-controlled characters. An implementation observes the World read-only and returns a Decision; it never mutates the World directly – Character::onTick applies the decision through the same World::moveCharacter and World::placeBomb methods the human player's input uses, so there is no duplicated movement/bombing logic between player and bots.
